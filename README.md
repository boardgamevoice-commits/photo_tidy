# PhotoTidy Developer Website

This is the developer website for PhotoTidy, a smart photo organization app for iOS.

## Files

- `index.html` - Main landing page
- `privacy.html` - Privacy policy
- `support.html` - Help and support page
- `netlify.toml` - Netlify deployment configuration

## Deployment

This website is deployed on Netlify and automatically updates when changes are pushed to the main branch.

## Content

All content is in English and provides information about:
- App features and benefits
- Privacy policy and data handling
- User guide and FAQ
- Contact information
